Text size

Use a fixed-width font. With a proportional one a line of wide capitals can still run off the edge.

−1 fits the font. 8 narrows it to the client's own cell, which lets any size wrap.

The client puts two ceilings on this. It breaks lines assuming every character is 8 pixels wide and never re-checks, so wider text runs off the right edge. And past 18 pixels tall it cuts the bottom of every line — underscores go first, then the tails of y, g and q. Nothing can be set to avoid that one, which is why the presets stop where they do.

Tabs

Name:channels, separated by |. * is everything, a leading - removes one. Channels: local, party, pm, guild, market, world, system, info, fd, gm.

e.g. CTRL+SHIFT+X. System-wide, so it is taken from every application. Leave empty for none.

Timestamps

The stamp sits at the start of the line, before the sender's name, so every channel lines up the same way. Colour only — the client's markup has no size code.

The client does not record when a message arrived, so the mod notes it as each one comes in. Anything already in the chat when the client started has no time to show and stays unstamped.

Scrolling

0 follows your Windows mouse setting, which is what every other application uses.

The chat window ships with scroll buttons but no wheel handling. This drives the client's own scroller, so it behaves exactly like pressing a button and the in-game chat overlay scrolls with it — they share one view position.

Cooldown

Three placeholders, in this order: %d the seconds left, %s the plural "s", %s the channel name. Colour markup works as it does anywhere else.

The numbers come from the client's own gate and its per-channel table, so this only reports what the client already decided. The server enforces the cooldowns either way — nothing here makes you able to post sooner.

Mentions

Normally detected automatically. Set this only if that stops working.

Window

Clears the message history, so the in-game overlay empties too. Leave empty for none.

Changes apply within a couple of seconds — no restart.
